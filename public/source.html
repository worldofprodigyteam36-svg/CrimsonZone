Why AGPL

The site depends on AGPL-licensed software that it actually uses: @mercuryworkshop/epoxy-transport (served to browsers at /epoxy/ and extended by public/epoxy-compat/index.mjs) and @mercuryworkshop/wisp-js (used by the server for the Wisp endpoint). Combining MIT code with AGPL code is allowed, but the combined work must be distributable under the AGPL. Whether a browser-loaded file that subclasses AGPL code makes the whole app a derivative work is a genuine gray area, so this project takes the conservative route and is licensed AGPL-3.0-only throughout.

Your rights under the AGPL (network use)

Because this software is offered to users over a network, AGPL section 13 entitles you to the corresponding source code. It is all in the repository linked from the footer of every page, and you can download it from the button at the top of this page.
